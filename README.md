# AI Portfolio — Muhammad Ibrahim

Agentic AI Developer portfolio showcasing automation workflows, AI chatbots, and full-stack projects with a modern Bento-style UI.

## Features

- Bento-inspired responsive UI with smooth animations and dark/light contrast
- Hero section with animated mobile mockup and floating tech badges
- Tech stack and experience timeline with high-contrast, readable cards
- Projects section with workflow screenshots and GitHub links
- Real-time Testimonials & 5-Star Ratings powered by Firebase Firestore
- Interactive review modal with star rating selection
- Instagram follow integration in the review modal
- Contact section with WhatsApp, GitHub, LinkedIn, and Instagram links
- Animated skills marquee tickers
- Fully scrollable, responsive layout

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Firebase (Firestore)
- n8n, Python, AI Agents, APIs

## Firebase Firestore

Reviews are stored in the `reviews` collection and synced in real time across all users.

## Getting Started

Open `index.html` in a browser. No build step required.

## Deployment

The site is static and can be deployed to any static host (GitHub Pages, Vercel, Netlify).
